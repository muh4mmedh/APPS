# Gym

A knee-safe workout guide and log for the phone. Four gym days and a knee
rehab list, with stick figure pictures and form steps for every exercise. You
log weight and reps per set and do a knee check after each session.

It's self-contained: nothing in this folder loads anything from outside it, so
it can move to its own repository as-is.

## What it does

- **Five tabs:** Day 1 (chest and shoulders), Day 2 (back and biceps), Day 3
  (legs, core and cardio), Day 4 (upper mix) and Rehab. On a gym day it opens
  that day's plan. On a rest day it opens the first gym day you haven't
  finished this week. Once all four are done, it opens Rehab.
- **Logging a set:** tap **Set 1** to log it with the numbers shown. Those
  numbers come from last session, so one tap repeats last time. Tap the
  numbers to change them first. The first time you do an exercise, the tick
  asks you for the weight. 0 means body weight.
- **Last time:** each exercise shows last session's numbers. Under them is one
  line of advice, and that advice only says go up if the knee felt fine:
  - The knee was fine and you hit the top of the rep range on every set: go up
    one step or add a rep.
  - The knee was fine but you didn't hit the top: same weight, one more rep.
  - The knee was a bit sore: repeat last time.
  - The knee felt off: same weight or lighter.
- **Knee check:** at the bottom of each day you pick Fine, A bit sore or Felt
  off, and can log body weight (optional). Felt off shows the stop-and-see-a-
  doctor warning. A red banner then stays at the top until a later session's
  check says otherwise.
- **History:**
  - every session, newest first
  - knee checks from the last 4 weeks
  - body weight change
  - the kg / lb switch (weights are stored in kg, so switching loses nothing)
  - export to a JSON file, and import one back to restore it
- **Offline:** the service worker precaches every file. After one visit, the
  app works with no signal and can be installed with *Add to Home Screen*.
- **Android app:** `android/build.sh` packs the same files into an APK that
  installs on its own. See [`android/README.md`](android/README.md).

Ticks start fresh each Monday. That's only because a tick means "logged in
this week's session", so nothing you've logged is ever thrown away.

## Files

```
index.html             the page
css/base.css           design tokens, copied from the Apps collection
css/app.css            this app's styles
js/data.js             the exercises (edit this to change the plan)
js/figures.js          the stick figure drawings
js/store.js            saved data and the rules (prefill, advice, which tab); no DOM
js/app.js              drawing and controls
sw.js                  offline cache; bump VERSION when files change
manifest.webmanifest   makes it installable
icons/                 generated by tools/make-icons.py (needs Pillow)
android/               the APK: WebView shell, build script, signing key
tests/                 logic tests (plain node) and browser tests (playwright)
```

## Running and testing

```sh
cd gym && python3 -m http.server 8001     # open http://localhost:8001/index.html
node gym/tests/store.test.cjs             # from the repo root, no install needed
node gym/tests/browser.test.mjs           # needs `npm install` at the repo root
```
